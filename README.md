# 🐍 365 Days of Python

Welcome to my **365-day Python challenge** — a personal journey to sharpen my coding skills, explore new libraries, and build a solid foundation for real-world problem-solving.

---

## 📅 Overview
This repository tracks my daily progress as I dive deeper into Python, covering everything from the basics to advanced topics like automation, cybersecurity scripting, data manipulation, and machine learning.  
Each day comes with:
- **Code snippets** and exercises  
- **Notes** explaining key concepts  
- **Mini-projects** to apply what I’ve learned  

---

## 🎯 Goals
- Master Python syntax, data structures, and OOP  
- Build automation and cybersecurity tools  
- Explore data analysis, APIs, and scripting  
- Develop the discipline of daily coding  
- Create a portfolio that actually proves skill, not just “interest”
